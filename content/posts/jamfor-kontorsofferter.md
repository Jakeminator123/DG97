Den ena offerten beskriver ett rum. Den andra räknar arbetsplatser. Båda nämner mötesrum, men ingen förklarar riktigt hur mycket ni får använda dem. Då är det för tidigt att jämföra totalsummorna.

Lägg erbjudandena bredvid samma beskrivning av ert behov. Målet är att förstå vad varje alternativ skulle innebära för en vanlig månad, inte att bara hitta det lägsta talet i dokumentet.

## Skriv ett gemensamt underlag

Beskriv hur många som behöver plats samtidigt, vilken utrustning ni använder och hur ofta ni har besök eller bokade möten. Ta med önskat inflyttningsdatum och sådant som ännu är osäkert. Skicka samma underlag till de alternativ ni jämför.

Om ett behov inte har beskrivits är det lätt att leverantörerna räknar på olika saker. En skillnad i offert kan då bero på antaganden snarare än på ett bättre eller sämre erbjudande.

## Bygg en jämförelse som visar luckorna

| Område | Alternativ A | Alternativ B | Uppgift att bekräfta |
| --- | --- | --- | --- |
| Rum eller arbetsplatser | | | Vilket utrymme disponerar ni? |
| Möbler och utrustning | | | Vad följer faktiskt med? |
| Mötesanvändning | | | Hur bokas den och vad är begränsat? |
| Löpande kostnad | | | Vilka tillägg behöver räknas med? |
| Start och förändring | | | Vad gäller vid inflyttning eller nytt behov? |

Fyll i det ni har fått bekräftat. Markera resten som obesvarat. Be om ett förtydligande i stället för att tolka ord som ”flexibelt” eller ”allt ingår” på egen hand.

## Pröva även en mindre vanlig månad

Gör först jämförelsen för er vardag. Titta sedan på en månad med fler kundbesök, en ny kollega eller ett projekt som kräver extra möten. Fråga hur erbjudandet fungerar i den situationen. Det hjälper er att upptäcka begränsningar som annars kommer fram först när ni redan har flyttat.

Det här är ett sätt att ordna frågor och kostnadsunderlag. Avtalsfrågor som kräver särskild bedömning bör ni ta vidare med rätt kompetens; guiden tolkar inte villkoren åt er.

## Gör en kort beslutsnotering

Skriv varför ett alternativ verkar passa bäst och vilka svar ni fortfarande behöver. Om beslutet senare ska förklaras för en kollega slipper ni börja om från muntliga minnen av en visning.
