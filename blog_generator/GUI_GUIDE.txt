🚀 QUICK START
================================================================================

STEP 1: SETUP (ONE TIME)
------------------------
1. Ensure .env file exists in project root with:
   OPENAI_API_KEY=your-api-key-here

2. Install dependencies:
   cd blog_generator
   pip install -r requirements.txt

3. Make sure Next.js dev server is running:
   cd dg97-site
   npm run dev

STEP 2: LAUNCH GUI
------------------
Double-click: launch_gui.bat

OR run manually:
python gui_generator.py

STEP 3: GENERATE POST
---------------------
1. Select category from dropdown
2. Select topic from dropdown (OR enter custom topic)
3. Choose frequency
4. Click "🚀 Generera & Publicera"
5. Wait 30-60 seconds
6. Post appears on http://localhost:3000/blogg

FREQUENCY OPTIONS
-----------------

1. PUBLICERA NU (EN GÅNG)
   - Generates one post immediately
   - No scheduling created
   - Use for one-off posts

2. DAGLIG PUBLICERING
   - Creates schedule for daily posts
   - Posts generated at 09:00 each day
   - Requires scheduler to be running

3. VARJE VECKA (MÅNDAG)
   - Posts every Monday at 09:00
   - Consistent weekly content

4. VARJE VECKA (ONSDAG)
   - Posts every Wednesday at 09:00
   - Mid-week engagement

5. TVÅ GÅNGER I VECKAN (MÅN + ONS)
   - Posts Monday and Wednesday
   - Recommended for active blogs
   - 2 posts per week = consistent engagement

================================================================================
⏰ SCHEDULER
================================================================================

WHAT IS IT?
-----------
The scheduler runs in the background and automatically generates posts
based on the frequency you selected in the GUI.

HOW TO USE
----------
1. Generate a post with frequency (not "once")
2. Schedule is created automatically
3. Run scheduler:
   python scheduler.py
   Choose option 1 (continuous)

SCHEDULER COMMANDS
------------------
1. Run scheduler (continuous)    - Keeps running, checks daily at 09:00
2. Check and generate now        - One-time check (for testing)
3. View schedule                 - See all scheduled posts
4. Test schedule                 - Dry run (no actual generation)
0. Exit

RUNNING SCHEDULER 24/7
----------------------
For production use, run scheduler as:
- Windows Service (nssm)
- Task Scheduler (Windows)
- systemd service (Linux)
- Background process with nohup

Example with nohup:
nohup python scheduler.py > scheduler.log 2>&1 &

🎨 IMAGE GENERATION
================================================================================

AUTOMATIC
---------
Every post automatically gets a relevant image generated by DALL-E 3.

IMAGE SPECS
-----------
- Size: 1792x1024 (landscape)
- Quality: Standard (HD available but more expensive)
- Format: PNG
- Location: dg97-site/public/images/blog/

IMAGE PROMPTS
-------------
Images are contextually generated based on category:

Startup:     Modern office with young entrepreneurs
Produktivitet: Focused professional at clean desk
Arbetsliv:   Balanced workspace, comfortable atmosphere
Ekonomi:     Professional business setting
Stockholm:   City views, Vasastan area
Nätverk:     Professionals networking in modern space

FALLBACK
--------
If image generation fails (API issues, rate limits):
- Post still created successfully
- Uses default image: /images/office_room.jpg
- You can manually replace later

================================================================================
🔧 TECHNICAL DETAILS
================================================================================

API INTEGRATION
---------------
Posts are saved directly to: dg97-site/content/posts/
The Next.js API route (pages/api/posts.js) automatically detects new files.
Blog page auto-refreshes every 3 seconds in development mode.

WORKFLOW
--------
1. GUI collects input
2. Calls generate_post() in background thread
3. GPT-4 generates ~1000 word article
4. DALL-E 3 generates featured image
5. Saves markdown file with frontmatter
6. File appears in dev server within 3 seconds

FILE STRUCTURE
--------------
Generated post:
---
title: "Post Title"
date: "2025-10-15"
excerpt: "SEO-optimized description"
featuredImage: "/images/blog/image.png"
featuredImageAlt: "Alt text"
category: "startup"
---

# Main Heading

Content here...

THREADING
---------
GUI uses background threading to prevent freezing during generation.
Main thread handles UI updates, worker thread does heavy lifting.

================================================================================
🐛 TROUBLESHOOTING
================================================================================

GUI WON'T START
---------------
→ Check Python installation: python --version
→ Install dependencies: pip install -r requirements.txt
→ Check .env file exists in project root

MISSING API KEY ERROR
---------------------
→ Verify .env file in project root (kontor/.env)
→ Check format: OPENAI_API_KEY=sk-...
→ No quotes needed around the key

GENERATION FAILS
----------------
→ Check OpenAI API status
→ Verify API key has credits
→ Check internet connection
→ Look for errors in status window

IMAGE GENERATION FAILS
----------------------
→ This is non-critical, post still created
→ DALL-E can be slow/unavailable
→ Check API rate limits
→ Uses fallback image automatically

POST DOESN'T APPEAR
-------------------
→ Check dev server is running (npm run dev)
→ Wait 3 seconds for auto-refresh
→ Manually refresh: http://localhost:3000/blogg
→ Check content/posts/ directory

SCHEDULER NOT WORKING
---------------------
→ Check if scheduler.py is running
→ View schedule: option 3 in scheduler menu
→ Test schedule: option 4 in scheduler menu
→ Check schedule.json file

ENCODING ERRORS
---------------
→ Windows encoding handled automatically
→ If persists, run through .bat launcher
→ Check console for specific error
