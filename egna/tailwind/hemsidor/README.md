# Hemsidor-mall (Tailwind)

## Installera (npm)
1) Se till att du har Node via nvm (t.ex. 24).
2) I projektmappen:

```bash
npm i -D eslint eslint-config-next prettier   tailwindcss postcss autoprefixer prettier-plugin-tailwindcss
```

## Kör
```bash
npm run dev
```

## Extensions (Cursor/VS Code)
- ESLint
- Prettier
- EditorConfig
- Tailwind CSS IntelliSense
